# 客户福利抽奖活动 H5

> 微信传播场景的活动抽奖页 · 独立设计 + 主导实现并部署上线（AI 协作开发）
> 原生 HTML / CSS / JavaScript · 腾讯云静态托管 · 微信分享卡片

## 一、项目背景

面向客户的福利派发活动，需要在微信内快速传播：客户扫码/点链接进入 → 填写信息 → 抽奖 → 中奖后截图找推荐人兑奖。要求**零门槛**（不注册、不登录）且**在微信里能正常分享**。

## 二、功能实现

| 功能 | 说明 |
|---|---|
| 抽奖逻辑 | 奖池配置化，中奖概率按活动规则设定（本次为 30%），前端即时出结果 |
| 参与表单 | 姓名 + 推荐人姓名，用于后续核对兑奖 |
| 防重复 | 「姓名组合 + 设备标识」双重判重，避免同一人反复抽取 |
| 测试模式 | 姓名与推荐人均填「测试」时直接放行，方便活动前完整走一遍流程，无需占用真实名额 |
| 微信分享卡片 | 配置 `og:image` / `og:description` / `og:site_name`，链接在微信内被分享时展示定制卡片而非默认缩略图 |
| 中奖留证 | 中奖结果页可直接截图，作为兑奖凭证，省掉后端核销流程 |

## 三、部署

使用腾讯云 CloudBase 静态托管部署，纯静态页面无需服务器，长期在线运行、零运维成本。
