## 一、解决什么问题

销售面谈现场经常被问到两个问题——「我到底该买多少保额？」「我退休后钱够不够？」

过去只能靠手算或者开 Excel 试算，慢、容易出错，客户看着也费劲。这个小程序把两个最常被问到的测算做成了**微信内打开即用**的工具，面谈时当场出结果。

## 二、核心功能

### 1. 重疾险保额缺口测算
根据客户的年龄、收入、负债与已有保障情况，测算重疾险的**保额缺口**，输出建议保额。

### 2. 养老金缺口测算
根据当前年龄、退休年龄、预期月支出与已有养老储备，测算退休后的**养老金缺口**，输出需要自备的金额。

## 三、这个项目最难的地方：精度

保险测算工具最怕「算得差不多」——差几百块，客户当场就会质疑专业性。

**做法**：把小程序的计算结果与公司正式计划书 PDF **逐项对照核验**，反复校准计算逻辑，直到两边**精确到元**完全一致。这个过程来回调了多轮，也是这个项目里最花时间的部分。

校准通过后，它才真正能替代 Excel 上场。
